# 1000Mark

A benchmark for any computer or phone, on one fixed scale where 1000 is a fast desktop. It tests the CPU, graphics, memory and storage, gives a score per part and a system score, and lets you compare devices and see where yours sits among everyone else's.

There are two tests: one that runs in the browser with nothing to install, and a small computer test (Windows, Mac, Linux) that reads the real hardware. Both show their results on the same pages.
